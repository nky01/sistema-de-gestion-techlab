# Sistema de Gestión - TechLab 🚀

Sistema de consola desarrollado en **Java** para la gestión integral de productos

---

## 📌 Funcionalidades

* **Gestión de Productos (CRUD):**
  * Agregar nuevos productos
  * Listar productos registrados
  * Consultar datos de un producto por codigo
  * Eliminar product, ingresando su codigo
---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Java (JDK 8+)
* **Estructuras de datos:** `ArrayList`
* **Entrada/Salida:** `java.util.Scanner`
